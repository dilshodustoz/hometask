# Hometask

Dilshod ustoz kursining IELTS uy vazifalari sahifalari (GitHub Pages).

- `listening/`, `reading/`, `writing/`, `speaking/` — har bir test o'z papkasida.
- O'quvchi shaxsiy havola (`?k=...`) bilan kiradi; javoblar Apps Script orqali tekshirilib, Telegram topic'iga yuboriladi.
- Javob kalitlari va o'quvchilar ro'yxati bu yerda emas, ustozning Google Drive'idagi yopiq "Hometask" papkasida turadi.
